==================================================
                 POKÉMON IGNO RED
                       v1.1
==================================================

Pokémon FireRed, but your Pokémon IGNORE you.

Pokémon Igno Red is a fan-made Pokémon FireRed ROM hack
made by AJMTV that completely changes the obedience system.

When a Pokémon disobeys, it may:

- Loaf around
- Ignore the command and miss
- Hurt itself
- Use another move from its moveset

Version 1.1 introduces a working alternate-move mechanic.
When a Pokémon disobeys, it can sometimes ignore the
selected move and use another move it knows instead.

Alternate moves must have PP available, and the Pokémon
cannot select the move you originally commanded.

--------------------------------
BASE ROM REQUIREMENT
--------------------------------

Required ROM:

1636 - Pokemon Fire Red (U)(Squirrels).gba

SHA-1:
41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc

The patch was created specifically against this ROM.

Using a different FireRed ROM, even another version of
FireRed (USA) (Squirrels), may result in the patch failing
or the game not working correctly.

The base ROM must be clean and unmodified.

The original Pokémon FireRed ROM is NOT included.

--------------------------------
HOW TO PLAY
--------------------------------

1. Obtain a clean copy of the required Pokémon FireRed
   (USA) (Squirrels) base ROM.

2. Download the Pokémon Igno Red v1.1 BPS patch.

3. Apply the BPS patch using a compatible patching tool.

 Recommended options:

   • Floating IPS (Flips):
     https://github.com/Alcaro/Flips

   • Rom Patcher JS (browser-based):
     https://www.marcrobledo.com/RomPatcher.js/

4. Select your clean FireRed ROM as the original ROM.

5. Select Pokemon_Igno_Red_v1.1.bps as the patch.

6. Apply the patch and save the resulting .gba file.

7. Open Pokémon Igno Red .gba in a
   compatible Game Boy Advance emulator.
